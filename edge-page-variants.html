Page variants — edge cases

Rules for creating, editing, deleting variants and changing the default. The default variant is always the Control in the page's experiments.

V1

Set a new default

Allowed only when no experiment on this page is running or scheduled. Draft experiments on the page switch their Control to the new default.
Make D the default?
Visitors to AI-Native Software Engineering Programme will see D · Counsellor-first layout instead of A. A stays as a variant you can switch back to.
1 draft experiment on this page uses A as Control. It will use D instead, and D will be removed from its variant list.
V2

Default locked during a test

While an experiment on the page is running or scheduled, "Set as default" is disabled for every variant, with the reason on hover.

DCounsellor-first layout5 changes
Locked: Online BBA — banner & sticky CTA is running on this page and uses the default as Control. Stop it to change the default.
V3

Delete a variant

Allowed for variants that aren't the default and aren't in a running or scheduled experiment.
Delete variant D?
Counsellor-first layout and its 5 section changes will be deleted. This can't be undone.
D is in 1 draft experiment. It will be removed from that experiment's variant list.
V4

Delete blocked

The default variant and variants in a running or scheduled experiment can't be deleted.
Can't delete A
A is the page's default. Make another variant the default first.
Can't delete B
B is in Online BBA — banner & sticky CTA (Running). Stop the experiment first.
V5

Variant limit

A page can have up to 5 variants, including the default. "New variant" is disabled at the limit.

BShort banner + sticky CTA3 changes
CVideo banner1 change
DCounsellor-first layout5 changes
EFee-first layout2 changes
New variant
5 of 5 variants. Delete one to add another.
V6

Editing the default during a test

A is Control. Its changes reach Control visitors, and also every section in B and C that is still "Same as A".
You're editing A (default), the Control of a running experiment. Changes go live right away. Sections in B and C marked "Same as A" change too, so the variants stay comparable.
Editing a section that B has its own copy of changes only A. B keeps its version.
V7

Switch variant with unsaved changes

Switching variants, going back or closing the tab with unsaved edits asks first.
Save changes to B?
You have unsaved changes in B · Short banner + sticky CTA. Switching to C will discard them.
V8

Reset a section to the default

Discards the variant's own copy of a section and links it back to A.
Reset Banner to A?
B's changes to Banner will be discarded. From now on, this section will match A and follow its changes.
V9

Move page to draft, or delete page

Blocked while the page has a running or scheduled experiment, because every variant would go offline mid-test.
Can't move BBA to draft
Online BBA — banner & sticky CTA is running on this page. Stop the experiment first. The same applies to deleting the page.
