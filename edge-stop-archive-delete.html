E3

Archive

Only stopped or draft tests. Archived tests leave the summary counts and move to the Archived tab.
Archive this experiment?
It moves to the Archived tab and stops counting in the summary strip. You can unarchive it any time.
E4

Delete

Drafts and stopped tests can be deleted. Running and scheduled tests must be stopped or unscheduled first.
Delete experiment?
AI-Native SE — fee block layout will be deleted. The page's variants aren't affected.
Can't delete a running experiment
Stop it first. Leads already tagged with its tracking key keep their tags.
E5

Duplicate

Copies setup into a new draft. The tracking key gets a new suffix, and the page default becomes the new Control.
Created Online BBA — banner & sticky CTA (copy) as a draft. Tracking key: online-bba-banner-cta-2. Control is now B (the page's current default).
E6

Unschedule

A scheduled test can go back to a plain draft.
Cancel the scheduled start?
